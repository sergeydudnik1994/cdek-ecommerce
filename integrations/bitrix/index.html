Пошаговая инструкция: как подключить СДЭК к 1С-Битрикс

Инструкция по настройке официального модуля СДЭК (от разработчика IPOL) по протоколу API v2.0.

1

Установите модуль из Маркетплейса 1С-Битрикс

В административной панели сайта перейдите в Marketplace → Каталог решений. Введите в поиске ipol.sdek (или «Интеграция со СДЭК»), загрузите и установите модуль в систему.

2

Авторизуйтесь по боевым ключам Rest API v2.0

В личном кабинете СДЭК для бизнеса перейдите в «Интеграция → Ключи API». Скопируйте Account и Secure password и вставьте их в настройках модуля: Настройки → Настройки модулей → СДЭК (IPOL) → Основные.

3

Синхронизируйте базу местоположений

Откройте вкладку «Местоположения» в настройках модуля СДЭК и запустите процесс сопоставления. Это свяжет города интернет-магазина 1С-Битрикс (структура 2.0) с внутренними кодами населенных пунктов СДЭК.

4

Активируйте службы доставки и виджет карты

В разделе «Магазин → Настройки → Службы доставки» создайте и включите обработчики доставки СДЭК: «Доставка курьером», «Самовывоз (ПВЗ)» и «Постаматы». Модуль автоматически подключит интерактивную карту выбора пунктов к вашему чекауту.

5

Настройте автоотгрузку и печать документов

Во вкладке «Автоматизация» задайте соответствие статусов: например, отправлять заказ в СДЭК при переходе статуса в «Оплачен» или «Собирается на складе». Настройте формат печати ШК-этикеток под ваш термопринтер.

Частые вопросы и решение ошибок в 1С-Битрикс

Ошибка «Не сопоставлен город доставки» при расчете корзины

Причина: местоположение покупателя в 1С-Битрикс не связано с кодом города СДЭК. Откройте Настройки модулей → СДЭК → Местоположения, нажмите «Импортировать города СДЭК» и запустите процедуру автоматической привязки.

Карта ПВЗ не открывается в компоненте оформления заказа (sale.order.ajax)

Чаще всего это вызвано конфликтом JavaScript в кастомизированном шаблоне оформления заказа или отсутствием API-ключа Яндекс Карт. В настройках модуля включите режим совместимости с кастомным чекаутом и пропишите ключ JS API карт.

Ошибка авторизации: «Неверный идентификатор клиента или пароль»

Убедитесь, что в настройках модуля выбрана версия API 2.0 и введены боевые параметры Account / Secure password из вкладки «Интеграция» личного кабинета СДЭК (логин и пароль от входа в ЛК не подходят).

Поддерживается ли печать термоэтикеток со штрихкодами 75х120 мм?

Да. В модуле предусмотрен выбор формата генерации документов: PDF-квитанция А4 или файл стикеров для термопринтеров (разрешение 200/300 DPI, формат 75x120 мм).
