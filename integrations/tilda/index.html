Пошаговая инструкция: как подключить СДЭК к Tilda за 5 минут

Официальная интеграция осуществляется через встроенный модуль доставки Tilda и ключи Rest API СДЭК.

1

Получите API-ключи в личном кабинете СДЭК

Авторизуйтесь в личном кабинете СДЭК (доступно для юрлиц, ИП и самозанятых с договором). Откройте раздел «Интеграция» → создайте пару ключей API v2.0: Account (идентификатор) и Secure password (секретный пароль).

2

Добавьте службу доставки CDEK в панели Tilda

В панели управления вашим сайтом на Tilda перейдите в «Настройки сайта» → «Доставка». Нажмите кнопку «Добавить сервис доставки» и выберите в списке официальный модуль CDEK.

3

Заполните параметры, тарифы и город отгрузки

Вставьте значения Account и Secure password. Укажите ваш город отправки по умолчанию, задайте дефолтный вес отправления и активируйте необходимые тарифы доставки (до пунктов выдачи, постаматов или курьером).

4

Активируйте СДЭК в блоке корзины ST100

Откройте редактор страниц интернет-магазина, перейдите в свойства блока корзины ST100 (или всплывающей корзины), откройте вкладку способов доставки и включите СДЭК. Опубликуйте все страницы сайта.

Часто задаваемые вопросы и решение проблем

Как подключить СДЭК к интернет-магазину на Tilda?

Для подключения оформите B2B-договор со СДЭК, сгенерируйте пару ключей API v2.0 (Account и Secure password) в личном кабинете и добавьте модуль CDEK в разделе «Настройки сайта → Доставка» в панели Tilda.

Где взять Account и Secure password для интеграции с Tilda?

API-ключи генерируются автоматически в личном кабинете СДЭК в разделе «Интеграция → Ключи API». Они доступны только для клиентов с действующим договором (Юрлица, ИП, Самозанятые).

Работает ли выбор пунктов выдачи на интерактивной карте в Tilda?

Да. При выборе доставки СДЭК в корзине ST100 покупатель может кликнуть «Выбрать на карте», открыть интерактивную карту с актуальными ПВЗ и постаматами своего города и сразу увидеть рассчитанную стоимость.

Почему виджет СДЭК не рассчитывает стоимость доставки в корзине?

Распространенные причины:
1. Не указан базовый город отправления в настройках модуля Tilda.
2. В каталоге у товаров не задан вес (если вес 0 г, расчет может блокироваться).
3. Использованы неверные или тестовые API-ключи вместо боевых параметров Rest API v2.0.

Как передавать заказы из Tilda в накладные СДЭК автоматически?

Все реквизиты заказа (город, адрес ПВЗ, ФИО, телефон) фиксируются в заявке Tilda CRM. Для создания накладных в 1 клик без ручного переноса можно использовать прямую связку по API или готовые вебхуки интеграции.
