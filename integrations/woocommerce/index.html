Пошаговая инструкция: как настроить плагин СДЭК в WooCommerce

Инструкция по настройке официального плагина cdekdelivery по протоколу API v2.0.

1

Получите ключи API v2.0 в личном кабинете СДЭК

В личном кабинете СДЭК для бизнеса перейдите в раздел «Интеграция → Ключи API» и скопируйте значения: Account (Идентификатор клиента) и Secure password (Секрет клиента).

2

Установите плагин cdekdelivery в панели WordPress

В админке сайта перейдите в Плагины → Добавить новый. В строке поиска введите cdekdelivery (или «Официальный модуль доставки СДЭК»), нажмите «Установить» и затем «Активировать».

3

Авторизуйтесь и укажите город отправления

Перейдите в меню WooCommerce → Настройки → Доставка → СДЭК. Вставьте Account и Secure password, сохраните изменения и убедитесь, что статус авторизации стал активным. Укажите ваш базовый город отгрузки и задайте габариты/вес по умолчанию.

4

Добавьте СДЭК в зоны доставки и подключите Яндекс Карты

В разделе WooCommerce → Настройки → Доставка → Зоны доставки откройте вашу зону (например, «Россия») и добавьте метод доставки СДЭК. В настройках метода вставьте JavaScript API-ключ Яндекс Карт для стабильной отрисовки карты ПВЗ в чекауте.

5

Проверьте работу чекаута и создание накладной

Оформите тестовый заказ: выберите пункт выдачи на интерактивной карте, проверьте сумму расчета. В панели WordPress откройте созданный заказ в разделе «WooCommerce → Заказы» и нажмите «Отправить в СДЭК» для формирования накладной и печати штрихкода.

Частые вопросы и решение ошибок в WooCommerce

Ошибка «CDEK error: 401 Unauthorized» при проверке ключей в WooCommerce

Убедитесь, что скопированы именно боевые ключи протокола API v2.0 из раздела «Интеграция → Ключи API» личного кабинета СДЭК (Account и Secure password), а не логин и пароль от входа в личный кабинет. Проверьте отсутствие лишних пробелов.

Почему карта ПВЗ не загружается на странице оформления заказа?

1. В настройках плагина не указан или заблокирован JavaScript API-ключ Яндекс Карт (получите бесплатный ключ в Кабинете разработчика Яндекса).
2. На странице оформления заказа используется блочный чекаут (Gutenberg Blocks). Для корректной работы виджета рекомендуется использовать классический шорткод [woocommerce_checkout].

Почему калькулятор СДЭК не считает доставку или пишет «Нет доступных способов»?

1. В товарах корзины задан нулевой вес (заполните базовый вес по умолчанию в настройках плагина).
2. Метод доставки СДЭК не добавлен в соответствующую «Зону доставки» WooCommerce (WooCommerce → Настройки → Доставка → Зоны доставки).
3. Не сопоставлен город получателя в чекауте.

Как настроить наложенный платеж в WooCommerce через СДЭК?

В разделе WooCommerce → Настройки → Платежи активируйте способ «Оплата при доставке» (COD). В настройках плагина СДЭК включите прием наложенного платежа — сумма заказа и признак оплаты при получении будут автоматически передаваться в накладную.
