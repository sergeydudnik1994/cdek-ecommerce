Интеграция СДЭК и Тильда: пошаговая настройка корзины ST100 и карты ПВЗ

Быстрый старт на Tilda:

Встроенный модуль СДЭК в корзину Tilda (блок ST100) позволяет клиентам выбирать пункт выдачи на интерактивной карте, автоматически рассчитывает стоимость доставки в реальном времени и отправляет заказы в ваш личный кабинет СДЭК.

Пошаговый процесс подключения

  1. 1. Заключение B2B-договора: Оформление официального договора со СДЭК для получения боевых API-ключей (Client ID и Client Secret).
  2. 2. Активация сервиса доставки: В панели Tilda перейдите в Настройки сайта → Платежные системы / Доставка → Добавить сервис «СДЭК».
  3. 3. Ввод ключей API: Укажите Client ID и Secret из личного кабинета, выберите доступные тарифы («Посылка склад-склад» и «Посылка склад-дверь»).
  4. 4. Привязка к корзине ST100: В блоке корзины включите поле выбора доставки СДЭК с интерактивной картой пунктов выдачи.
